# DECLARAR
* Sirve para decirle a la máquina que nos reserve una pequeña parte de la memoria para guardar, por ejemplo, una varible, y utilizarla en un futuro.

* Mi versión: It serve for say to the machine that it reserve a little part of the memory for store, for example, a variable, and use it in the future.

# CONST
* Declarar una variable constante, cuyo valor nunca va a cambiar y siempre es el mismo. Por ejemplo el numero de documento o el DNI.

# LET
* Declarar una variable que puede funciona de manera local, o sea, para reservar memoria de manera temporal. Cuando una función termina de cumplir su misión o cuando ya no se necesita en el momento de ejecutar un aplicación, esta deja de ejecutarse y libera memoria.

# VAR
* Declarar una variable que puede funciona de manera global. o sea, para reservar memoria de manera permanente. Cuando una función se ejecuta, esta no dejará de ejecutarse hasta que la aplicación no se cierre, y así, hasta ese momento, se liberará memoria.

# ARRAY
* Si volvemos al mismo ejemplo de las variables, el de la caja, basicamente es el mismo proceso, podemos guardar sola cosa, por ejemplo, esferos. La diferencia, es que en la caja tendremos varios separadores. Digamos que en el primero guarda un esfero con un grosor de 0,4 mm de grosor en la punta, en el segundo separador un esfero con un grosor de 1,0 mm, y en el último y tercero, tenemos un esfero con un grosor de 1,4 mm.
